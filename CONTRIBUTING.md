# Contributing

Keep changes focused and open one small pull request per improvement.
Use Conventional Commits, for example `fix: handle empty input` or
`docs: clarify setup`. Write pull request titles and descriptions in English.

Read the README for setup and available checks. Run the relevant checks before
opening a pull request and include the commands and results in the description.
For browser examples, include the browser tested and a screenshot for UI changes.
If a check cannot be run, say so rather than claiming it passed.

Do not commit credentials, local configuration, dependencies or generated files.
Keep existing author credits and licensing terms. Report security concerns
privately as described in SECURITY.md.
