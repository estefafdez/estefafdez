# Security

These repositories contain learning examples, not production-ready applications.
Only the current default branch is maintained; old commits and examples may use
outdated dependencies.

## Reporting a vulnerability

Use this repository's **Security > Report a vulnerability** option when available.
If private reporting is unavailable, contact the maintainer at
estefafdez@gmail.com. Do not open a public issue containing exploit details,
credentials or personal data.

Include the affected file or dependency, reproduction steps and potential impact.
There is no guaranteed response time or supported release schedule.
